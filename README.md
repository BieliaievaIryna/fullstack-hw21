# JavaScript Basics Project

## Опис
Цей проект демонструє базові можливості JavaScript:
- Робота з Каруванням
- Робота з функціями вищого порядку
- Робота з вкладеними функціями

## Структура проекту
- **index.html** — базова HTML-сторінка.
- **curriedAdd.js** — функція додавання чисел.
- **curriedDomain.js** — функція побудови доменного імені.
- **modifyFunction.js** — функція модифікації іншої функції.
- **nestedFunctions.js** — функція множення аргументів.

## Використані функції

### curriedAdd
Реалізація Функції з Каруванням для Послідовного Додавання Трьох Чисел.

### curriedDomain
Реалізація Функції з Каруванням для Побудови Повного Доменного Імені.

### modifyFunction
Розробка Вищої Функції для Модифікації Поведінки Іншої Функції.

### nestedFunctions
Розробка Функції Трирівневої Вкладеності в JavaScript з Конкретною Операцією.
